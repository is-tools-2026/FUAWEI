## 🛠 Реализованный функционал

### 🟢 Зеленый блок (Базовый)
1. **Инициализация проекта** — настроена структура и каркас плагина.
2. **Кнопка в Toolbar** — выводит приветственное сообщение "Hello, World! [Имя]".
3. **Контекстное меню** — добавлен кастомный пункт при клике правой кнопкой мыши на файл.
4. **Интеграция с Git** — проект опубликован в организации.

### 🟡 Желтый блок (Дополнительный)
1. **Подсчет строк (4 балла)** — инструмент анализирует текущий файл и выводит статистику пустых строк, строк кода и комментариев.
2. **Таймер Кодера (3 балла)** — отображает время текущей сессии программирования в статус-баре.

### 🔴 Красный блок (Сложный)
1. **Мини-игра «Змейка» (15 баллов)** — интерактивная игра, запускающаяся прямо в отдельном окне (Tool Window) редактора IDE. Змейка управляется с клавиатуры, растет при поедании «багов» и считает очки сессии.

## 🚀 Инструкция по запуску
1. Склонировать репозиторий: `git clone https://github.com/is-tools-2026/FUAWEI.git`
2. Открыть проект в IDE (IntelliJ IDEA / PyCharm / VS Code).
3. Дождаться индексации и сборки проекта Gradle/NPM.
4. Запустить плагин через конфигурацию `Run IDE` или `Extension`.
